# SO-100 机械臂「抓积木入盒」模仿学习模型 · 技术参数

> 用途：项目介绍 / 汇报材料。所有数字均为本机实测，非估算。
> 生成时间：2026-11-14

---

## 一、任务定义

机械臂从**折叠初始位**出发 → 伸向桌上的粉色积木块 → **夹住** → 抬起 → **放进纸盒** → 回到初始位。
全程由策略自主完成，人类只在每次开始前把积木摆回原位。

| 项目   | 数值                                                                            |
| ---- | ----------------------------------------------------------------------------- |
| 机器人  | SO-100 结构 6 自由度机械臂（主从臂，leader/follower）                                       |
| 舵机   | 飞特 STS3215 ×6（ID 1–6），1 Mbaud                                                 |
| 串口   | follower = COM6，leader = COM5（CH343 USB 转串口）                                  |
| 关节   | shoulder_pan / shoulder_lift / elbow_flex / wrist_flex / wrist_roll / gripper |
| 控制方式 | 位置控制，动作以**角度（度）**为单位下发                                                        |
| 相机   | 2 路：`laptop`（侧视）+ `phone`（俯视），640×480 @30 fps                                 |

## 二、训练数据集

| 项目     | 数值                                                                                    |
| ------ | ------------------------------------------------------------------------------------- |
| 数据集 ID | `pick/so100_test`                                                                     |

| 总帧数    | **13 009 帧**                                                                          |

| 观测     | 2 路 RGB（3×480×640）+ 6 维关节角                                                            |

演示的收尾高度一致：**50 条里绝大多数末帧积木都在盒子里**，动作序列干净，适合直接训练。

## 三、模型

**ACT（Action Chunking Transformer）**，即 ALOHA 论文的动作分块 Transformer。

| 参数          | 数值                                                                            |
| ----------- | ----------------------------------------------------------------------------- |
| 可训练参数量      | **51 597 190（≈51.6 M）**                                                       |
| 总参数量        | 51 597 238（≈51.6 M）                                                           |
| 模型文件        | `model.safetensors`，197.1 MB（含优化器状态的 checkpoint 为 413 MB）                     |
| 视觉主干        | ResNet18（ImageNet 预训练）                                                        |
| Transformer | dim_model 512 / 8 头 / **4 层编码器** / 1 层解码器 / FFN 3200 / dropout 0.1            |
| VAE         | 开启，latent 32，4 层编码器，`kl_weight = 10`                                          |
| 动作分块        | `chunk_size = 100`（一次预测 3.33 秒的动作）                                            |
| 推理执行        | 训练时整块执行（100 步）；**实际部署改为每 10 步重新观察并重规划**                                       |
| 输入          | `observation.images.laptop`、`observation.images.phone`、`observation.state`(6) |
| 输出          | `action`(6) × 100 步                                                           |

## 五、训练指标

在训练集上固定抽取 **64 个样本**测得（in-sample，用来比较不同步数的收敛情况，不代表泛化性能）：

| 检查点          | l1_loss（归一化） | kld_loss   | 动作块平均误差   | 首步（实际下发）误差 |
| ------------ | ------------ | ---------- | --------- | ---------- |
| 10 000 步     | 0.0957       | 0.0012     | 2.70°     | 2.86°      |
| 20 000 步     | 0.0713       | —          | —         | —          |
| 30 000 步     | 0.0605       | —          | —         | —          |
| **40 000 步** | **0.0545**   | **0.0002** | **1.52°** | **1.70°**  |

逐关节误差（40k，100 步平均）：

| 关节     | shoulder_pan | shoulder_lift | elbow_flex | wrist_flex | wrist_roll | gripper |
| ------ | ------------ | ------------- | ---------- | ---------- | ---------- | ------- |
| MAE（度） | 1.07         | 2.45          | 2.15       | 1.23       | 0.88       | 1.33    |

**从 10k 到 40k，l1 下降 43%，且仍在以每万步约 11% 的速度下降，没有出现平台期** → 说明 40k 仍属欠训练。

## 六、真机评估结果（实测）

评估口径：`control_robot.py record -p <模型>`，策略驱动机器人自主执行，人工只负责每轮把积木摆回原位。

| 配置                   | 轮数  | 下探并回位      | 实际完成（进盒/夹住）                         |
| -------------------- | --- | ---------- | ----------------------------------- |
| 每轮 10 秒，动作块 100 步盲执行 | 30  | 10/30（33%） | **约 6/30（20%）**                     |
| 每轮 20 秒，每 10 步重规划    | 15  | 11/15（73%） | **7–10/15（47–67%）**；另有 3 轮夹住但时间到未放下 |

**速度对比（同一段动作）**

| 指标     | 人类演示    | 模型回放                |
| ------ | ------- | ------------------- |
| 伸到积木耗时 | 4.8 秒   | 7.7 秒               |
| 完整循环   | 7.1 秒   | 10.4 秒              |
| 关节峰值速度 | 163 °/s | 208 °/s（偶发 736 °/s） |

模型的峰值速度**高于**演示，但整体更慢 → 主要问题是**轨迹有多余修正与犹豫**，不是电机速度不足。

## 七、部署链路（为保证可复现做过的修复）

| 问题                           | 处理                                                              |
| ---------------------------- | --------------------------------------------------------------- |
| 训练脚本找不到 ffmpeg（`WinError 2`） | 改为优先使用 `imageio-ffmpeg` 自带 ffmpeg；编码器由 `libsvtav1` 改为 `libx264` |
| 摄像头打开耗时 5–28 秒并偶发崩溃          | 摄像头后端改为优先 DirectShow（打开时间降到 1.6–2.1 秒）                          |
| 评估退出后舵机锁死、无法手动回位             | `disconnect()` 前先关闭力矩                                           |
| 录完数据缺少 mp4/meta_data         | 提供 `consolidate_dataset.py` 从 episode + PNG 帧重建可训练数据集           |

## 八、当前局限与下一步

1. **欠训练**：40k 步 l1 仍在线性下降，计划续训至 100k（约 6 小时），预期动作更干脆、单轮耗时接近演示的 8 秒。
2. **成功率**：目前 50–70%（视每轮时长与重规划间隔），尚未达到稳定可交付水平。
3. **标定**：使用的是初始占位标定（homing offset 全 2048、drive mode 全 1），采集与推理一致所以可用，但没有物理意义上的零点；若更换机械臂或重新标定，**必须重新采集数据**。
4. **数据量**：50 条演示偏少；若要提升泛化（不同积木位置/朝向），需补采 30–50 条并保持场景一致。
